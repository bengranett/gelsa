gelsa.esa.azulero_gui#

Compact live editor for the azulero IYJH colour image of the MER stamps.

The boxes are those of the Continuum colour tab of gelsa.esa.line_map_studio, with the same defaults, laid out beside the image so the whole thing fits in a notebook cell:

from gelsa.esa import azulero_gui
colour = azulero_gui.make_azulero_gui(stamps, wcs)
colour

Every change redraws the image. colour.rgb() is the current RGB image and colour.transform() the azulero.image.color.Transform behind it, so a setting found here can be handed on, e.g. to LineMapStudio.apply_transform.

Number boxes for the azulero transform beside a live preview.

Parameters:

  • stamps (numpy.ndarray) – (4, ny, nx) stack of VIS, NIR_Y, NIR_J, NIR_H stamps.

  • wcs (astropy.wcs.WCS) – WCS of the stamps, for the sky axes and for azulero.

  • transform (azulero.image.color.Transform, optional) – Where to start; the studio’s defaults if not given.

  • image_px (int) – Width of the preview in screen pixels.
